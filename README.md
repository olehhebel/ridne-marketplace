# РІДНЕ / RIDNE

Trust-first Ukrainian local-food marketplace foundation.

## Brand promise
LOCAL FOOD. REAL PRODUCERS. VISIBLE ORIGIN. VERIFIED TRUST.

## Current scope
This repository contains the marketplace discovery UI, five-step web onboarding, buyer/producer cabinets and a Supabase Edge API. Product and review examples are explicitly labelled. Production email activation is still required; see backend/web/README.md. Existing Telegram workflows and journal URLs remain available.

## Local run
Serve the repository root with any static server, for example:

```bash
python3 -m http.server 8080
```

## Deployment
Configured for Vercel. Canonical production domain is planned as `https://ridne.store/`.

## Product rules
The authoritative project instructions remain outside this public repository. Key invariant: trust, producer legitimacy, food safety and transaction integrity outrank growth shortcuts.
